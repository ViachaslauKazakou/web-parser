# ForumScope workspace

## Surface
Web application workspace at `/`; Operate. Audience: a single local operator collecting public forum posts/topics, reviewing relevance evidence, exporting results and revisiting completed analyses. Sources: public forum search/topic URLs and JSON/CSV imports, with manual entry as a fallback. Constraints: no login, no internal forum dependencies, local/trusted-network use only, deterministic scoring by default, optional external LLM. Synthetic examples must be labeled.

## Direction contract

THESIS: ForumScope makes every parsing and ranking step inspectable in one working surface; it refuses both an empty dashboard that hides the next action and a botanical costume that obscures the forum data.

OWN-WORLD: Translate the selected botanical folio into a warm field ground, deep leaf-green navigation/shell, sage and graphite data roles, fine sepia separators, and scarlet only for a selected/high-priority state. Use a readable modern sans UI face with restrained italic topic titles and compact uppercase metadata. The signature move is a registered, fixed-scale evidence ruler aligned on the same baseline for every ranked reply. All inputs, tabs, tables, buttons and navigation remain familiar web controls.

STORY: The operator chooses a forum URL, a username/ID search, JSON/CSV, or manual data; inspects the collected discussion; runs deterministic relevance ranking; expands feature evidence and reasons; then exports the result or revisits it from history. LLM scoring/explanations are opt-in and never block the deterministic result.

FIRST VIEWPORT: At desktop widths, a narrow dark-green navigation rail anchors the left; a compact workspace header and health state sit above the main task. The first work area combines source tabs, a URL/file/manual input and one primary action. Below it, the topic summary leads directly into a ranked response table with aligned evidence rulers; a quiet right rail carries score distribution, best/low summaries and export. On mobile, navigation collapses to a top bar, collection controls precede results, and each evidence ruler retains a labeled fixed 0–100 scale.
